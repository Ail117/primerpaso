# PrimerPaso

Plataforma web para conectar a estudiantes y recién egresados con prácticas, becas y empleos de nivel inicial.

## 🚀 ¿Qué es PrimerPaso?

PrimerPaso es una plataforma diseñada para apoyar a jóvenes en el inicio de su carrera profesional, ofreciéndoles oportunidades reales y herramientas útiles para su desarrollo laboral.

## 📁 Estructura del proyecto

```
primerpaso/
├── assets/         # Archivos estáticos (CSS, JS, imágenes)
├── includes/       # Header, footer, navbar
├── views/          # Vistas públicas
├── dashboard/      # Paneles privados de usuarios o empresas
├── index.php       # Punto de entrada
└── router.php      # Encargado de redirigir las vistas
```

## 🧪 Requisitos

- PHP 7.4 o superior
- Laragon, XAMPP o similar
- Navegador moderno
- Git

## 🛠️ Cómo trabajar en equipo

1. Crea una rama desde `dev`:
   ```bash
   git checkout dev
   git checkout -b tu-rama
   ```

2. Trabaja y haz commits:
   ```bash
   git add .
   git commit -m "Lo que hiciste"
   ```

3. Sube tu rama:
   ```bash
   git push -u origin tu-rama
   ```

4. Abre un Pull Request en GitHub para unirlo a `dev`.

## 📦 Ramas principales

- `main`: Código en producción
- `dev`: Código en desarrollo
- `login`, `empleos`, `registro`, etc.: funcionalidades específicas

## 👥 Equipo

- Usa Pull Requests para colaborar.
- Siempre parte desde `dev`.
- Sigue buenas prácticas de commit y ramas.
